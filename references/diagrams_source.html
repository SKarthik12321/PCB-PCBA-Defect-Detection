01. UML Class Diagram - GACGDF Model Architecture

        classDiagram
            class GACGDFModel {
                +backbone : GeometryBackbone
                +dacsr : DACModule
                +neck : CARFTNeck
                +head : DetectionHead
                +loss : GradBalancedLoss
                +forward(x)
                +train_step(batch)
            }

            class GeometryBackbone {
                -n_stages : int
                -channel_widths : list
                +extract_features(x)
            }

            class DACModule {
                -alpha : float
                -beta : float
                +fuse_multi_scale(features)
            }

            class CARFTNeck {
                -transformer_blocks : int
                -n_heads : int
                +context_aware_tuning(f)
            }

            class DetectionHead {
                -n_classes : int
                -anchors : tensor
                +predict(f)
            }

            class GradBalancedLoss {
                -w_cls : float
                -w_box : float
                +compute_loss(preds, targets)
            }

            GACGDFModel *-- GeometryBackbone
            GACGDFModel *-- DACModule
            GACGDFModel *-- CARFTNeck
            GACGDFModel *-- DetectionHead
            GACGDFModel *-- GradBalancedLoss

02. Sequence Diagram - Inference & Inspection Pipeline

        sequenceDiagram
            autonumber
            actor U as PCB Manufacturer
            participant B as Backend (FastAPI)
            participant D as PCBDetector
            participant M as GACGDFModel
            participant V as Visualizer

            U->>B: Upload PCB Image
            B->>D: invoke predict(image_path)
            D->>M: preprocess & forward(tensor)
            M->>M: 1. Extract Geo-Spatial Features
            M->>M: 2. Multi-Scale Fusion (DACSR)
            M->>M: 3. Contextual Tuning (CARFT)
            M->>D: Return BBox & Classes
            D->>V: Apply NMS & Overlay Labels
            V->>B: Final Annotated Image
            B->>U: Display Inspection Results
